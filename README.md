# Hand FX

A simple browser-based hand-tracking camera with interactive visual filters.

## Run
Open `index.html` from a local web server (camera permissions usually require HTTPS or localhost).

## Features
- MediaPipe hand landmark tracking
- Neon hand trails
- Spark, heart, and ring fingertip effects
- Up to two tracked hands

## Privacy
The camera stream is processed in the browser; this demo does not upload video to a server.
